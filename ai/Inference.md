# Red Hat AI Inference (rhaii)
A container image
- variant options in [Red Hat Ecosystem Catalog](https://catalog.redhat.com/en/search?q=rhaii)
- supports data center grade AI accelerators only.




can be deployed
- in OpenShift Container Platform clusters
- on standalone Red Hat Enterprise Linux (RHEL) hosts with Podman
- integrated with Red Hat OpenShift AI for managed AI/ML workflows.
